# Product Overview

## What is this?

A Vietnamese e-commerce website for school supplies and stationery products. The site is a Single Page Application (SPA) that allows customers to browse products, manage shopping carts, and place orders, while administrators can manage inventory, promotions, and customer reviews.

## Target Users

- **Customers**: Students, parents, and office workers looking to purchase school supplies online
- **Administrators**: Store owners/managers who need to manage products, promotions, and customer feedback

## Core Features

### Customer Features
- Browse 9+ school supply products with images, prices, and descriptions
- Search and filter products by name, category (Bút viết, Vở/Sổ, Dụng cụ học tập), and brand
- View detailed product information in modal dialogs
- Add products to shopping cart and manage cart items
- Complete checkout with delivery information and payment method selection
- User registration and login
- Submit product reviews and ratings (1-5 stars)
- View promotional banners and student discount offers

### Admin Features
- Secure admin login with session management
- CRUD operations for products (add, edit, delete)
- Manage student promotions and discount offers
- Review and moderate customer feedback
- Lock/unlock admin sessions for security

## Key Characteristics

- **Client-side only**: No backend server - all data stored in browser LocalStorage
- **Vietnamese language**: All UI text and content in Vietnamese
- **Responsive design**: Works on desktop, tablet, and mobile devices
- **Fast performance**: < 1.5s page load, no server requests
- **Simple deployment**: Static files only, can be hosted anywhere

## Business Domain

School supplies and stationery e-commerce, focusing on:
- Writing instruments (pens, pencils)
- Notebooks and paper products
- Study tools (calculators, rulers, backpacks)
- Student-focused promotions and discounts
